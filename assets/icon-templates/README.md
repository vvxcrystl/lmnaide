# Icon templates

Placeholders at the right sizes. Draw over the `art` group, delete the `guides` group, and send the files back.

| File | Canvas | What it's for |
|---|---|---|
| `launcher-foreground.svg` | 108×108 (exported as 432 px) | Home-screen icon art, transparent background. Keep important art inside the red 66 circle; only the blue 72 square is ever visible. |
| `launcher-background.svg` | 108×108 | Fills the whole canvas behind the foreground. A flat color is fine. |
| `launcher-monochrome.svg` | 108×108 | Single-color silhouette for Android 13+ themed icons. |
| `menu-icon.svg` | 24×24 (exported as 96 px) | The icon next to "Calendar" in the side menu. Keep art inside the red 20×20 square. |

If you work in PNG instead: 432×432 px for each launcher layer, 112×112 px for the menu icon, all with transparency. Play Store listings also need a separate 512×512 px PNG.
